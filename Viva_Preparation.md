# Viva Preparation

1. **Why Employee ID Search?** Employee IDs are unique keys and are suitable for demonstrating storage and searching.
2. **Why compare these structures?** They use different search strategies: ordered tree traversal, balanced tree traversal and hash indexing.
3. **What is BST?** A binary tree where smaller keys are stored to the left and larger keys to the right.
4. **What is AVL?** A self-balancing BST that maintains the height difference of left and right subtrees within -1 to +1.
5. **Name AVL rotations.** LL, RR, LR and RL.
6. **What is hashing?** A hash function maps a key to an array index.
7. **What is a collision?** Two different keys map to the same table index.
8. **What is Linear Probing?** On collision, check the next slot sequentially until an empty slot or the required key is found.
9. **What is a successful search?** Searching for an ID present in the dataset.
10. **What is an unsuccessful search?** Searching for an ID absent from the dataset.
11. **Why use one dataset?** It makes the comparison fair because each structure stores the same records.
12. **What is inorder traversal?** Visit left subtree, node, then right subtree; in a BST/AVL it prints IDs in ascending order.
